# Entrega de Maquetación Front End

Prototipo visual no funcional desarrollado en Angular. Simula la navegación entre pantallas de la aplicación web de gestión de medicamentos y alarmas, con datos hardcodeados y sin lógica de negocio.

## Pantallas incluidas

**Medicamentos**
- Lista de medicamentos (con y sin notificación, variantes 0/1/2)
- Lista con 3 registros
- Crear medicamento
- Editar medicamento
- Eliminar medicamento (variantes 1/2/3)
- Confirmación

**Alarmas**
- Lista de alarmas (sin notificación, con notificación, con notificación para recalcular)
- Confirmación alarma recalculada

## Requisitos

- [Node.js](https://nodejs.org/) v18 o superior

## Cómo ejecutar

```bash
npm install
npx ng serve
```

Abre el navegador en `http://localhost:4200`
